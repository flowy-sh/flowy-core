# Growth Marketing — routing refresh (compact)

Funnel order; each gate exits on a named artifact. Fire the skill as `marketing-skills:<name>` BEFORE producing the asset.

- new product/audience · "who is this for?" · "why buy/churn?" → `marketing-skills:customer-research` (brief: 3 pains + 5+ quotes)
- write/rewrite a page · weak copy → `marketing-skills:copywriting` (1 headline + subhead + 1 CTA, each tied to a quote)
- not ranking · SEO audit · organic dropped → `marketing-skills:seo-audit` (top 5 fixes, each keyword/page-tagged)
- cold outreach · no replies · prospecting → `marketing-skills:cold-email` (first touch + 2+ follow-ups, per-prospect signal)
- Product Hunt · GTM · "about to ship" → `marketing-skills:launch` (dated channel checklist + owned-channel capture)
- live page not converting → `marketing-skills:cro` (top 3 blockers ranked, each with a fix)
- about to claim "this worked" → `marketing-skills:ab-testing` FIRST (hypothesis + metric + baseline + sample size; no win until significant)

Collision: Blocked > Scope-changed (re-Research) > Done-check (ab-testing) > lifecycle order > advisory > default (ask one question).
Any other marketing intent (ads, social, emails, pricing, analytics, product-marketing, ...) → `marketing-skills:<name>`.
